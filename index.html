About factory data

Factory is attributed only for Lem units whose lot/batch matched a fulfillment sheet — the live Stord ("Hello Nancy.Orders.Lots") and Portless ("Hello Nancy Batch Tracing") sheets, joined by order number. Each covers only part of the window so far, so units ordered outside their coverage show no factory yet — this chart fills in as both sheets grow.
